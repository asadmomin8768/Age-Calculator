# Age Calculator

A simple and responsive **Age Calculator** that calculates a person's age from their date of birth.

## ✨ Features

* Enter date of birth
* Calculate age instantly
* Displays years, months, and days
* Simple and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **JavaScript date calculations, user input handling, and DOM manipulation**.
